# EAV Index for Image Search

## Overview

This directory contains SQL templates for building an efficient Entity-Attribute-Value (EAV) index for image search functionality. The EAV approach provides:

- **Compact storage**: ~30-50MB vs 16GB with word tokenization
- **Fast queries**: Indexed lookups on entities, attributes, and values
- **Flexible schema**: Easy to add new tables/columns
- **Pure SQLite**: Minimal PHP, maximum database efficiency

## Architecture

### Core Tables

1. **Entities** - Root entity IDs (mediaID values)
2. **Attributes** - All column names from all tables
3. **ValuesText** - Unique text values (referenced by ID)
4. **EAV** - Main index (Eid, Aid, Vid/ValueNumber)

### Metadata Tables

1. **TableNames** - Registry of imported tables
2. **Relationships** - Defines entity graph connections
3. **NumericFields** - Lists numeric vs text fields

### Temporary Tables

1. **EAV_STACK** - Transition table during UNPIVOT (dropped after completion)

## Performance Configuration

### Batch Size Tuning

The EAV import process uses batched transactions for optimal performance. The batch size can be configured based on your system's available memory.

**Check your system's recommended batch size:**
```bash
php index.php images status
```

Look for the "Memory & Performance" section which shows:
- Current memory limit
- Recommended batch size
- Configured batch size
- Status (OK or WARNING)

**Configure batch size in config.php:**
```php
'mod' => [
    'images' => [
        'eav_batch_size' => 27000  // Adjust based on status output
    ]
]
```

**Guidelines:**
- 128MB memory → 27,000 batch size (default)
- 256MB memory → 100,000 batch size
- 512MB+ memory → 100,000 batch size (capped)

See `config_example.php` for complete configuration options.

## Usage

### Quick Start - Proof of Concept

Test the approach with just the media table:

```bash
# 1. Import media table
sqlite3 test.db < import_media.sql

# 2. Run proof-of-concept
sqlite3 test.db < templates/sql/images/eav/test_media_only.sql

# 3. Verify results
sqlite3 test.db "SELECT * FROM EAV LIMIT 10;"
```

### Full EAV Index Build

Build complete EAV index for all tables:

```bash
# Option 1: Use CLI command (recommended)
php index.php images build-eav-index

# Option 2: Manual steps
php index.php images generate-eav-sql
sqlite3 images_cache.db < /var/www/temp/bioc/data/eav_inserts.sql
```

### Step-by-Step Manual Process

```bash
# 1. Import all tables (all TSV format)
sqlite3 images_cache.db <<EOF
.headers on
.mode tabs
.import media.tsv media
.import occurrences.tsv occurrences
.import collections.tsv collections
.import taxa.tsv taxa
.import taxstatus.tsv taxstatus
EOF

# 2. Run setup
sqlite3 images_cache.db < templates/sql/images/eav/setup_metadata.sql

# 3. Generate UNPIVOT SQL
php index.php images generate-eav-sql

# 4. Execute UNPIVOT SQL
sqlite3 images_cache.db < /var/www/temp/bioc/data/eav_inserts.sql

# 5. Finalize
sqlite3 images_cache.db < templates/sql/images/eav/finalize_eav.sql
```

## SQL Templates

### setup_metadata.sql

Creates and populates:
- TableNames registry
- Relationships map
- NumericFields registry
- Attributes table (auto-populated from schemas)
- Entities table (from media.mediaID)
- EAV_STACK (empty, ready for data)

### unpivot_template.sql

Template showing the structure of generated UNPIVOT SQL. The actual SQL is generated by `EavSqlGenerator` based on current table schemas.

### finalize_eav.sql

Creates final tables:
- ValuesText (from EAV_STACK)
- EAV (compressed format)
- All indexes for fast queries
- Cleanup of temporary tables

## Data Flow

```
MySQL Tables
    ↓
TSV Export (all tables)
    ↓
SQLite Import (raw tables)
    ↓
setup_metadata.sql → Metadata tables + Entities
    ↓
generate-eav-sql → eav_inserts.sql (UNPIVOT)
    ↓
Execute UNPIVOT → EAV_STACK populated
    ↓
finalize_eav.sql → Final EAV tables + indexes
    ↓
EAV Index Ready for Queries
```

## Query Examples

### Search by text value

```sql
SELECT DISTINCT e.EntityValue as mediaID
FROM EAV eav
JOIN Entities e ON e.Eid = eav.Eid
JOIN ValuesText v ON v.Vid = eav.Vid
WHERE v.ValueText LIKE '%Lepomis%';
```

### Search by attribute and value

```sql
SELECT DISTINCT e.EntityValue as mediaID
FROM EAV eav
JOIN Entities e ON e.Eid = eav.Eid
JOIN Attributes a ON a.Aid = eav.Aid
JOIN ValuesText v ON v.Vid = eav.Vid
WHERE a.ColumnName = 'scientificName'
AND v.ValueText LIKE '%humilis%';
```

### Search by numeric value

```sql
SELECT DISTINCT e.EntityValue as mediaID
FROM EAV eav
JOIN Entities e ON e.Eid = eav.Eid
JOIN Attributes a ON a.Aid = eav.Aid
WHERE a.ColumnName = 'occid'
AND eav.ValueNumber = 2707904;
```

### Reconstruct original record

```sql
SELECT 
    e.EntityValue as mediaID,
    a.TableName || '.' || a.ColumnName as Attribute,
    COALESCE(v.ValueText, CAST(eav.ValueNumber AS TEXT)) as Value
FROM EAV eav
JOIN Entities e ON e.Eid = eav.Eid
JOIN Attributes a ON a.Aid = eav.Aid
LEFT JOIN ValuesText v ON v.Vid = eav.Vid
WHERE e.EntityValue = 123456
ORDER BY a.TbId, a.Aid;
```

## Performance Expectations

### Storage

| Component | Estimated Size (195K media) |
|-----------|----------------------------|
| Entities | ~2MB |
| Attributes | <1KB |
| ValuesText | ~10-20MB |
| EAV | ~15-30MB |
| **Total** | **~30-50MB** |

### Query Performance

- Entity lookup: O(log n) via index
- Attribute lookup: O(log n) via index
- Value lookup: O(log n) via index
- Full-text search: O(n) on ValuesText (can add FTS5 if needed)

## Customization

### Adding New Tables

1. Add to `TableNames` in `setup_metadata.sql`
2. Add relationships to `Relationships`
3. Add numeric fields to `NumericFields`
4. Regenerate UNPIVOT SQL: `php index.php images generate-eav-sql`

### Adding New Numeric Fields

Update `NumericFields` in `setup_metadata.sql`:

```sql
INSERT INTO NumericFields (TableName, ColumnName) VALUES
    ('your_table', 'your_numeric_column');
```

### Changing Root Entity

Currently uses `media.mediaID` as root entity. To change:

1. Update `Entities` population in `setup_metadata.sql`
2. Update join logic in `EavSqlGenerator.php`

## Troubleshooting

### "unescaped quote character" errors

Ensure quotes are escaped in TSV files:
```bash
# Escape quotes in all TSV files
for file in *.tsv; do
    sed 's/"/\\"/g' "$file" > "${file}.tmp" && mv "${file}.tmp" "$file"
done
```

### Large database size

Check if original tables were dropped:
```sql
.tables  -- Should only show EAV tables
DROP TABLE IF EXISTS media;  -- Drop if still present
VACUUM;  -- Reclaim space
```

### Slow queries

Verify indexes exist:
```sql
.indexes EAV
```

Should show: `idx_eav_eid`, `idx_eav_aid`, `idx_eav_vid`, `idx_eav_valuenum`
